# Video-Game-Sales-Analysis-Tableau-
Interactive Tableau dashboard analyzing video game sales trends across platforms, genres, publishers, and regions.

## 📊 Project Overview

This project focuses on analyzing video game sales data using Tableau.

An interactive dashboard was created to explore sales trends across different platforms, genres, publishers, and regions and to identify key patterns in video game sales.

## 🎯 Objectives

- Analyze video game sales across different platforms
- Identify popular video game genres
- Analyze sales by region
- Explore publisher performance
- Identify sales trends over the years
- Present insights through an interactive Tableau dashboard

## 🛠️ Tools & Technologies

- Tableau
- Data Analysis
- Data Visualization
- Interactive Dashboard

## 📌 Key Analysis

- Sales by platform
- Sales by genre
- Sales by publisher
- Regional sales analysis
- Year-wise sales trends
- Comparison of video game performance

## 💡 Key Insights

The dashboard provides insights into video game sales patterns and helps understand how sales vary across platforms, genres, publishers, regions, and years.
